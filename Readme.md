# Tamper-Proof Cyberbullying Evidence Preservation Tool

## Description
Cyberbullying victims are often legally unprotected — not because evidence didn’t
exist, but because it was deleted, altered, or improperly captured before reporting.
Screenshots lack metadata. Platforms remove flagged content. Victims panic.
Build a browser extension and mobile tool that captures harassment in real time:
freezing page state, extracting metadata (URL, timestamp, sender ID), and storing
cryptographically hashed evidence locally and on a secure vault.
Output should be a structured legal report exportable to PDF, ready for law en-
forcement or institutional complaint submission.
Deliverable Expected Output
A browser extension + mobile app with:
• One-click real-time evidence capture with full metadata extraction
• SHA-256 cryptographic hashing for tamper-proof verification
• Encrypted cloud storage vault
• Auto-generated legal-format incident reports (PDF export)
